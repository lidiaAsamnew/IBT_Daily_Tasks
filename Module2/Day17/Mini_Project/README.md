# TeleBirr Loyalty Points Module

This project is a simple loyalty-points module for a TeleBirr shop.

## What it does

The module allows a customer to:

- Earn points from spending money.
- Redeem points.
- Check their current points balance.
- Use different earning rules.

The normal rule gives 1 point for every 10 ETB spent.

A holiday rule can give double points.
