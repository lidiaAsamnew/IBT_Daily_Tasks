# Lidia Asamnew — Portfolio

Personal portfolio website for Lidia Asamnew, Software Engineering student at Addis Ababa University.

Originally built from the Bedimcode Bianca HTML/CSS/JavaScript starter, then migrated to React with Vite. The visual design, content, and interactions match the original site.

## How to run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

To create a production build:

```bash
npm run build
npm run preview
```

Internet access is needed on first install. The contact form opens your email app (`mailto:`) with the message filled in. There is no server-side mail backend.
